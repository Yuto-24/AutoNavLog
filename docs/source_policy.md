# 出典・provenance方針

AutoNavLogは、アプリケーションが採用する計算・表示Policyと、公開可能な一次資料の出典をRepositoryに記録します。

航空大学校の内部運用資料については、資料を参照して設計・検証した事実だけを公開します。章節、ページ、見出し、原文要約、ファイルhash、規則と実装値の対応表など、原資料の内容を再構成しやすくする詳細な対応情報は現行source treeへ含めません。

このため、Repositoryで`AutoNavLog Policy`、`internal reviewed reference`等として記載する値や規則には、公開していない詳細provenanceを別途確認して採用したものがあります。Repositoryの記載だけから、航空大学校の公式規程・手順そのものを再現することは意図していません。

一方、SR22 AFM/POH、AIP、法令、国土交通省・国土地理院等の公開資料については、計算の検証やデータ更新に必要な範囲で文書名、版、ページ、URL、hash等を保持する場合があります。

## 実装Policyと出典の分離

AutoNavLogの動作を再現するために必要な計算値・固定値・アルゴリズム・テストはRepositoryへ保持します。

内部資料について非公開にするのは、主に次のような「原典との対応情報」です。

- 章・節・項番号
- 原典の見出しや本文要約
- ページ番号
- 内部資料ファイルのSHA-256
- 原典の個別箇所と実装値を結び付ける監査表

そのため、Repository上の実装からAutoNavLogの挙動自体を確認・再現することはできますが、個々のPolicyが内部資料のどこに記載されているかは公開情報として扱いません。

## 注意

AutoNavLogは非公式の地上準備支援ツールです。Repositoryに含まれるPolicyや参照値は、航空大学校その他の機関による公式承認や、実運航への適用性を意味しません。実際の飛行では最新の公式資料、機体資料、気象・航空情報、ATC指示を優先してください。
