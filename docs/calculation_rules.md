# Calculation Rules

- 測地線はWGS84、Courseは初期真方位、Leg中点は測地線上の中点です。
- 東偏差を正として`MC = TC - VAR`、右WCAを正として`MH = MC + WCA`とします。
- QNHは出発空港・ETDの`MSM推定QNH`を全Projectへ使用し、欠損時は手動入力必須です。
- PAの未丸め値と500 ft計画値を分け、初期Policyは`CEILING`です。
- 上昇表は指定軸内だけ線形補間し、高度軸だけ表端から500 ft以内の外挿を許可します。
- 巡航表は補間せず、65%近傍候補から燃料最大、ETE最大、KTAS最小の順で選びます。
- 降下は500 fpm、12 GPH、到着はCAS 121 kt、原則無風、12 GPHです。
- 反復計算は同じForecast Runで最大5回行い、代表時刻差30秒未満を収束とします。
- 内部値は丸めず、表示時にhalf-upで方位1°、距離0.5 nm、時間0.5 min、燃料0.1 galへ
  丸めます。
- 不明値は後続も未確定とし、0、1013.25 hPa、最近傍気象へフォールバックしません。

RCA/EOCが全経路端を越える場合はBlockerです。RCAが全経路内で最初の変針点を越える
場合だけ、利用者が承認できるWarningとします。
